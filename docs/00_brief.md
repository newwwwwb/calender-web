# 00 Brief — 차계부

- 날짜: 2026-11-05
- 소유자: Product Owner
- 요구 원본: [docs/superpowers/specs/2026-11-05-carbook-design.md](superpowers/specs/2026-11-05-carbook-design.md) (사용자 승인, 커밋 88b3f15). 이 문서와 다르면 원본을 따른다.

## 한 줄 목표
로그인한 사용자가 지금 캘린더 웹 안에서 자기 차량의 주유·정비·지출 기록, 소모품 교체 시기, 만기일(보험·자동차세·정기검사), 지출 통계를 한곳에서 관리하고, 교체일과 만기일은 캘린더 일정으로도 본다.

## 사용자 문제
- 주유·정비 지출이 영수증, 메모, 별도 앱에 흩어져 월 지출과 연비를 알기 어렵다.
- 엔진오일·필터 교체 시기와 보험·세금·검사 만기를 잊는다. 이미 쓰는 캘린더에 이 날짜가 보이지 않는다.

## 대상 사용자
- 이 캘린더 웹에 로그인한 본인. 차량 1대 이상. 공유하지 않는다.

## 제약
- 기존 캘린더 화면 배치·동작과 캘린더 코드(`useCalendar`, 화면 컴포넌트)를 바꾸지 않는다(원본 AC-2).
- 라우터 라이브러리를 추가하지 않는다. `App.tsx`의 기존 주소 분기(`matchShareId`) 방식으로 `/car`를 연다.
- 데이터는 Supabase. 새 테이블 4개는 `supabase/schema_carbook.sql`에만 두고 기존 스키마 파일은 고치지 않는다. 모든 행은 RLS(`auth.uid() = user_id`).
- 로그인하지 않으면 차계부를 쓸 수 없다(로컬 저장 없음).
- 범위 밖: 푸시 알림, 번호판 자동 조회, 영수증 사진, 예약, 차량 공유, 로컬 모드 저장.

## 기한
- 사용자가 지정하지 않았다(열린 질문으로 두지 않는다. 마일스톤은 PRD에서 제안).

## 사용자가 지정한 스택
- 지금 저장소 스택 그대로: React 19, TypeScript, Vite, Supabase(`@supabase/supabase-js`), date-fns, vitest + Testing Library, oxlint. 새 의존성 없음.

# v0.2 Brief — 차계부 계정 영역 (2026-11-21, 범위 확정)

- 요청 원문(사용자, god 경유): "차계부 쪽에는 로그아웃이나 로그인 버튼이 없는거 같은데 맞아 ? 내 정보를 확인한다던가 설정하는 부분도 없어보이고"
- 현재(v0.1.0 운영 배포): 차계부는 비로그인 때 로그인 버튼만 있다. 로그인 뒤에는 계정 표시·로그아웃·설정이 없다. 로그아웃은 캘린더의 설정 시트(`AuthButton`)에만 있어 차계부 사용자는 캘린더로 돌아가야 로그아웃할 수 있다.

## 사용자 문제
- 차계부 화면에서 지금 어느 계정으로 로그인했는지 알 수 없다.
- 차계부에서 바로 로그아웃할 수 없다.
- 차계부 동작을 사용자에게 맞출 설정이 없다(예: 처음 열 때 보일 차량).

## 후보 (god가 사용자에게 제시, 범위 미정)
1. 차계부 상단에 로그인 계정 표시 + 로그아웃
2. 차계부 설정(기본 차량, 추천 주기 초기화 등)
3. 캘린더와 설정 시트 공통화

## 제약 (v0.1과 같음, 사용자 답에 따라 바뀔 수 있음)
- 기존 캘린더 화면·코드 불변(원본 AC-2, 예외 1건: Overlay.tsx). 후보 3은 이 제약에 걸린다.
- 새 앱 의존성 없음. 스택은 v0.1과 같다.

## 기한
- 사용자가 정하지 않았다.

## 함께 처리할 백로그 후보 (verdict.md 5장)
- AC-04-9 재측정, P3 2건(1280px 재시도 버튼 줄바꿈, 만기일 확인창 퇴장 중 포커스).

## 확정 범위 (사용자 답 2026-11-21)
- 포함 1: 차계부 상단에 로그인 계정 표시(Google 프로필 사진·이름·이메일) + 로그아웃. 계정 삭제 없음.
- 포함 2: 차계부 설정 두 가지. a) 처음 열 때 보일 기본 차량 b) 추천 교체 주기를 기본값으로 되돌리기. 그 밖 없음.
- 포함 3: v0.1 백로그 3건(AC-04-9 재측정, 1280px 재시도 버튼 줄바꿈, 만기일 확인창 퇴장 중 포커스).
- 제외: 캘린더와 설정 화면 공통화. 캘린더 화면·코드 불변 유지.
