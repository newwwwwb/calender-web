## 1. 용어집

| 용어 | 뜻 | 쓰이는 곳 |
|---|---|---|
| 차계부 | 차량 지출·교체·만기일을 기록하는 이 제품의 `/car` 화면 | 전체 |
| 파일철 탭 | 화면 오른쪽 가장자리의 세로 탭 2개("캘린더", "차계부") | F-01, F-13, F-14 |
| 차량 | 사용자가 등록한 자동차 한 대. 별칭으로 구분한다 | F-03 |
| 별칭 | 차량 이름(예: `출퇴근`). 일정 제목에 들어간다 | F-03, F-08 |
| 기록 | 지출 한 건. 종류 7가지 | F-04 |
| 종류(기록) | 주유 fuel · 정비 maintenance · 세차 wash · 보험 insurance · 세금 tax · 주차 parking · 기타 other | F-04 |
| 가득 주유 | 연료통을 가득 채운 주유. 연비 계산의 기준점 | F-05 |
| 연비 | 주행거리 ÷ 주유량(km/L). 가득 주유 두 건 사이 구간별로 계산 | F-05 |
| 구간(연비) | 이웃한 가득 주유 두 건 사이 | F-05 |
| 현재 주행거리 | max(차량 주행거리, 그 차량 기록 중 최대 주행거리) | F-03, F-04, F-06 |
| 교체 항목 | 소모품 하나의 교체 주기 설정(예: 엔진오일 10,000km/12개월) | F-06 |
| 추천 주기 | 차량을 새로 만들 때 채우는 7개 교체 항목의 기본값. 참고용 | F-03, F-12 |
| 마지막 교체일/마지막 교체 주행거리 | 교체 항목을 마지막으로 교체한 날짜·주행거리 | F-06 |
| 하루 평균 주행거리 | 최근 90일 안 기록으로 구한 일 평균 주행거리 | F-06 |
| 다음 교체일 | 개월 기준 날짜, km 기준 날짜 중 이른 날 | F-06 |
| 남은 거리 | 마지막 교체 주행거리 + km 주기 − 현재 주행거리(마지막 교체 주행거리가 비어 있으면 없음) | F-06 |
| 곧 교체 | 다음 교체일이 오늘~30일 이내이거나 남은 거리가 1,000km 이하 | F-06 |
| 교체 시기 지남 | 다음 교체일이 오늘보다 앞이거나 남은 거리가 0 미만 | F-06 |
| 교체 완료 | 교체 항목의 마지막 교체일·주행거리를 새로 적는 동작 | F-06 |
| 주행거리 기록 부족 | 하루 평균을 구하지 못한 상태(최근 90일 안 주행거리 기록이 2건 미만, 첫·마지막 기록의 날짜 차이가 0일, 주행거리 차이가 0 이하 중 하나) 또는 마지막 교체 주행거리가 비어 km 기준을 계산하지 못한 상태 | F-06 |
| 만기일 | 보험 만기, 자동차세 납부 기한, 정기검사 만기. 사용자가 직접 입력 | F-07 |
| 정기분(자동차세) | 6월 30일, 12월 31일까지 내는 자동차세 | F-15 |
| 연결 일정 | 교체 항목·만기일과 이어진 캘린더 일정 | F-08 |
| 연결 id(`event_id`) | 연결 일정의 id. F-16에서 공유 상대에게 숨기는 일정의 판정에도 쓰임 | F-08, F-16 |
| '차계부' 카테고리 | 연결 일정이 쓰는 사용자 소유 카테고리. 지워지면 다음에 차계부를 열 때 다시 만들어 연결 일정을 다시 묶는다 | F-08, F-16 |
| 반영 실패 | 항목은 저장됐으나 캘린더 일정 쓰기가 실패한 상태 | F-08 |
| 공유 상대 | 캘린더를 공유한 다른 사용자 | F-16 |
| 위젯 모드 | `?widget=1`로 여는 바탕화면 작은 창 모드 | F-13 |
| FAB | 모바일의 새 일정 둥근 버튼 | F-14 |
| RLS | 행 단위 접근 제한. 본인 행만 읽고 쓰게 하는 DB 정책 | NFR-24 |
| 토스트 | 화면 아래에 잠시 뜨는 기존 알림 장치 | F-10 |
| 오늘 | 사용자 기기의 지역 날짜 | 1.1 |

## 2. 데이터 사전

공통: 4개 테이블 모두 `id`(고유 식별자), `user_id`(작성 사용자, 계정 삭제 시 함께 삭제), `created_at`(만든 시각)을 가진다. 차량에 딸린 3개 테이블은 `vehicle_id`(차량 삭제 시 함께 삭제)를 가진다.

### 2.1 `vehicles` (차량, F-03)

| 필드 | 의미 | 필수 | 예시값 |
|---|---|---|---|
| name | 별칭 | 필수, 1~20자 | `출퇴근` |
| model | 차종 | 선택, 30자 이하 | `아반떼 CN7` |
| year | 연식 | 선택, 1950~올해+1 | `2022` |
| plate | 번호판 | 선택, 15자 이하 | `12가3456` |
| odometer_km | 차량에 입력한 현재 주행거리(km) | 선택, 0~9,999,999 | `48000` |

### 2.2 `car_records` (기록, F-04)

| 필드 | 의미 | 필수 | 예시값 |
|---|---|---|---|
| kind | 종류 | 필수 | `fuel` |
| date | 기록 날짜 | 필수 | `2026-11-05` |
| amount_won | 금액(원, 정수) | 필수, 0~999,999,999 | `65000` |
| odometer_km | 그 시점 주행거리(km) | 선택 | `48120` |
| liters | 주유량(L, 소수 둘째 자리) | 선택, 주유만 | `38.45` |
| full_tank | 가득 주유 여부 | 선택, 주유만, 기본 거짓 | `true` |
| memo | 메모 | 선택, 200자 이하 | `고속도로 주유소` |

### 2.3 `car_maintenance_items` (교체 항목, F-06)

| 필드 | 의미 | 필수 | 예시값 |
|---|---|---|---|
| name | 항목 이름 | 필수, 1~30자 | `엔진오일` |
| interval_km | km 주기 | km·개월 중 하나 이상, 1~999,999 | `10000` |
| interval_months | 개월 주기 | 위와 같음, 1~600 | `12` |
| last_date | 마지막 교체일 | 필수 | `2026-05-01` |
| last_odometer_km | 마지막 교체 주행거리(km) | 양식에서 km 주기가 있으면 필수. 주행거리 없는 차량의 추천 항목은 비어 있을 수 있고 첫 주행거리로 채운다(BR-06a) | `40000` |
| event_id | 연결 일정 id | 선택(일정이 있을 때) | `3f2a…` |

### 2.4 `car_due_dates` (만기일, F-07)

| 필드 | 의미 | 필수 | 예시값 |
|---|---|---|---|
| kind | 종류 | 필수 | `insurance`(보험), `car_tax`(자동차세), `inspection`(정기검사) |
| due_date | 만기일 | 필수 | `2027-03-10` |
| event_id | 연결 일정 id | 선택 | `9c1b…` |

### 2.5 기존 테이블 중 차계부가 쓰는 필드(변경 없음)

| 테이블.필드 | 차계부의 쓰임 | 값 |
|---|---|---|
| categories.name | 카테고리 이름 | `차계부` |
| events.title | 일정 제목 | `[내 차] 엔진오일 교체 예정` · `[내 차] 보험 만기` · `[내 차] 자동차세 납부` · `[내 차] 정기검사 만기` |
| events.all_day | 종일 | 참 |
| events.start_at / end_at | 날짜 | 같은 날짜 문자열 `2027-03-10` |
| events.category_id | 카테고리 | '차계부' 카테고리 id |

### 2.6 계산값(저장하지 않음)

| 값 | 정의 | 예시 |
|---|---|---|
| 현재 주행거리 | BR-07 | 차량 48,000, 기록 최대 48,120 → 48,120 |
| 하루 평균 주행거리 | BR-12 | 90일 중 1,000km 차이 ÷ 30일 = 33.3km/일 |
| 남은 거리 | BR-13 | 40,000 + 10,000 − 48,000 = 2,000 |
| 다음 교체일 | BR-13 | `2027-01-04` |
| 상태 | BR-14 | 정상 · 곧 교체 · 교체 시기 지남 |
| 연비 | BR-11 | (10,500−10,000) ÷ (20+30) = 10.0km/L |
| 월별·종류별 합계 | BR-26 | 2026-11 주유 90,000원 |
