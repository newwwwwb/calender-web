- 날짜: 2026-11-05 · 작성: Tech Researcher · 최종 결정: Software Architect
- 이번 버전 범위 밖(원본 10장). 결론: 번호판만으로 개인 차량 정보를 주는 공개 API는 확인하지 못했으므로 **직접 입력 유지**를 권장한다.
- 표기: **확인** = 아래 URL에서 직접 읽음, **미확인** = 확인 못 함.

## 결론과 권장
1. 지금은 차종·연식을 사용자가 직접 입력하게 유지한다. 번호판 조회 API는 이번 조사에서 확인되지 않았다.
2. 다음 버전에서 다시 검토하려면 먼저 아래를 확인한다.
   - 국가법령정보센터의 자동차관리법 제69조·제69조의2, 시행령 제14조의3·제14조의4 현행 문구.
   - 민간 API(예: CODEF)의 자동차 상품 존재 여부, 요금, 약관, 인증 방식(사용자 공동인증서 로그인이 필요한지).
   - 개인정보: 번호판은 소유자를 특정할 수 있는 정보라 외부 서비스로 보내면 처리 방침과 동의 문구가 필요할 수 있다. 이 조사는 법률 자문이 아니다.
3. `vehicles.plate`는 본인만 읽는다(RLS). `vehicles`에는 공유 select 정책이 없어 캘린더 공유 상대에게 보이지 않는다. 다만 일정 제목에 번호판을 넣으면 공유 상대에게 보인다 → `tech.md` Q1.
